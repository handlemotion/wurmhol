---
title: "Quickstart"
description: "Share a dev server in a couple of minutes."
---

<Steps>
  <Step title="Sign up">
    Sign in at [dirt.wurmhol.com](https://dirt.wurmhol.com) and subscribe your org. You don't need a token to start, the first pipe from a computer asks you to approve it.
  </Step>
  <Step title="Open a pipe">
    ```bash
    npx wurmhol 8787
    ```

    It prints the pipe's link and returns, so the agent can keep working. The first time on a computer with no token, the link is an approval page instead: approve the computer there and it opens the pipe, and later pipes from that computer open straight away. To skip the approval, for CI or a long-lived environment, create a token under Tokens and set `WURMHOL_TOKEN`. The link is new every time unless you [give the pipe a name](/pipes#a-url-that-stays). The wall's Create pipe button copies this command for you, or a prompt to paste to your agent.

    <img className="shot" src="/images/create-light.webp" alt="The Create pipe card on the wall, with Copy agent prompt, Copy npx command and Copy setup for this computer" width="1680" height="1050" />

  </Step>
  <Step title="Open the link">
    Tap it on your phone or laptop and sign in once. Hot reload works too, browser WebSockets go through the pipe and the CLI sends `Host: localhost:<port>`, so Vite and most dev servers need no config.
  </Step>
  <Step title="Stop it">
    ```bash
    npx wurmhol stop 8787
    ```

    Or end it from the wall. If nobody does, it ends on its own after 4 hours.

  </Step>
</Steps>

To have your agent do all of this by itself, set it up once in [With your agent](/agents).
