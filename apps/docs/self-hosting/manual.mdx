---
title: "Deploy by hand"
description: "Create the database and deploy with wrangler, without the button."
---

From a clone of the repository.

```bash
pnpm install
cd apps/worker
pnpm exec wrangler d1 create wurmhol            # note the database id
D1_DATABASE_ID=<id> node scripts/deploy-cloudflare.mjs --config-only
pnpm exec wrangler d1 migrations apply DB --remote --config wrangler.deploy.jsonc
```

Then deploy with your hostnames.

```bash
D1_DATABASE_ID=<id> WORKER_DOMAIN=dirt.example.com,api.example.com,app.example.com \
  WORKER_ROUTE='*.example-pipes.dev/*' WORKER_VAR_BETTER_AUTH_URL=https://dirt.example.com \
  WORKER_VAR_SHARE_DOMAIN=example-pipes.dev WORKER_VAR_CONNECT_HOST=api.example.com \
  WORKER_VAR_APP_ALIASES=app.example.com \
  pnpm --filter @wurmhol/worker deploy:cloudflare
```

Then add the one required secret, from `apps/worker`.

```bash
pnpm exec wrangler secret put BETTER_AUTH_SECRET   # paste the output of openssl rand -base64 32
```

Any other var goes in as `WORKER_VAR_<NAME>`. For deploys on every push, connect the repository to Workers Builds with the build command `pnpm --filter @wurmhol/web build`, the deploy command `pnpm --filter @wurmhol/worker deploy:cloudflare` and the variables above as build variables. The rest of the setup is in [Domains](/self-hosting/domains) and [Sign-in and billing](/self-hosting/configuration).
