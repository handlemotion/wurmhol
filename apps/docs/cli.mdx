---
title: "CLI"
description: "Every command, flag and variable of `npx wurmhol`."
---

| Command                         | Does                                                           |
| ------------------------------- | -------------------------------------------------------------- |
| `wurmhol <port>`                | Open a pipe to a port, print its link and return               |
| `wurmhol ls`                    | List open pipes and when each one ends                         |
| `wurmhol stop <port\|id\|name>` | End one, or every one with `--all`                             |
| `wurmhol init`                  | Tell this repo's agents how to share, `--skill` adds the skill |
| `wurmhol login`                 | Approve this computer in the browser and save a token          |
| `wurmhol logout`                | Delete the saved token                                         |
| `wurmhol mcp`                   | Run the [MCP server](/mcp) on stdio                            |

## Flags

| Flag                     | Does                                                                        |
| ------------------------ | --------------------------------------------------------------------------- |
| `--ttl 8h`               | How long the pipe lasts, like `90m` or `8h`. 4 hours by default, 12 at most |
| `--name my-app`          | Open it at `https://my-app.wurmhol.dev`, the same URL every time            |
| `--only a@x.com,b@y.com` | Only these org members can open it                                          |
| `--note "text"`          | A line of text on the pipe's card, up to 280 characters                     |
| `--link <url>`           | A link on the pipe's card                                                   |
| `--json`                 | Print JSON, `{url, port, id, endsAt}` for a pipe                            |

## Variables

| Variable              | Does                                                     |
| --------------------- | -------------------------------------------------------- |
| `WURMHOL_TOKEN`       | Your org's token. Wins over one saved by `wurmhol login` |
| `WURMHOL_URL`         | Your own install, if you [self-host](/self-hosting)      |
| `HTTPS_PROXY`         | The proxy to go through                                  |
| `NODE_EXTRA_CA_CERTS` | Your proxy's certificate                                 |

When something fails, the error is one line with what to do about it. Node 22 or later.
