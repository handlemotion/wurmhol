---
title: "Self-hosting"
description: "Run Wurmhol on your own Cloudflare account."
---

The code is open source: AGPL-3.0 for the app, MIT for the CLI. One Cloudflare account, two
hostnames and `wrangler deploy` are enough to run it.

Point the CLI at your install with `WURMHOL_URL`:

```bash
WURMHOL_URL=https://api.example.com npx wurmhol login
```
